# classrooms.json 数据格式约定

教室调研结果放到本目录 `classrooms.json`，`app.html` 会自动加载并接入搜索
（无此文件时功能静默跳过，不报错）。

## 格式

```json
[
  {
    "code": "W1-C-512",
    "building": 494148473,
    "floor": "5",
    "name_zh": "",
    "name_ja": "",
    "name_en": "",
    "aliases": ["ウエスト1号館512", "West 1 512"]
  }
]
```

| 字段 | 必填 | 说明 |
|------|------|------|
| `code` | ✅ | 官方教室编号（课表/门牌上的写法），搜索主键 |
| `building` | ✅ | 所在建筑的 **OSM way id**（整数）。对照表见下 |
| `floor` | 建议 | 楼层，纯数字或 "B1" |
| `name_*` | 可选 | 教室名（如 "大讲义室"），无名教室留空 |
| `aliases` | 建议 | 别名/学生俗称/课表变体写法，全部进搜索索引 |

## building 字段怎么填

`data/annotations-claude.json` 的 key 就是 OSM way id，含 77 栋主要建筑的三语名，
直接按名字反查。常用建筑速查：

- West 3号馆 = 167423390 · 西講義棟 = 167423392 · Big Leaf = 494148473
- Center 1~6号馆 = 165694547 / 165694554 / 329404792 / 900236665 / 165694577 / 222850629
- East 1/2号馆 = 770575334 / 770575335 · 大講義室Ⅰ/Ⅱ = 770575332 / 770575333
- 中央図書館 = 770575330 · 椎木講堂 = 617112195 · 理系図書館 = 166554943

West 1/2/4/5 号馆的轮廓归属尚在人工裁定中（见 tools/out/REVIEW.md），
这几栋的教室可先用 `"building_pending": "west1"` 占位，别硬填 id。

## 调研时顺便确认

1. 九大教室编号规则（如 226 是否 = 2号馆2层26室？各 Zone 规则是否一致）
2. 编号在课表系统（campusmate）里的确切写法（搜索要和课表一致才有用）
3. 主要大教室的俗称（学生实际怎么叫）
