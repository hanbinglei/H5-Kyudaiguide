# classrooms.json 数据说明

`app.html` 自动加载本目录的 `classrooms.json` 并接入搜索（无此文件时功能静默跳过，不报错）。
搜房号 → 结果列表给出所在**楼与楼层** → 点进去定位到那栋楼。

## 格式

```json
[
  {
    "code": "1209",
    "building": 165694547,
    "floor": "2",
    "name_ja": "センター1号館 1209",
    "name_zh": "",
    "name_en": "",
    "aliases": ["センター1号館1209"],
    "seats": 30,
    "source": "https://www.kyushu-u.ac.jp/ja/university/facility/use/kougishitsu/"
  }
]
```

| 字段 | 必填 | 说明 |
|------|------|------|
| `code` | ✅ | 官方教室编号（课表/门牌上的写法），搜索主键 |
| `building` | ✅ | 所在建筑的 **OSM way id**（整数）。必须同时满足：`annotations-claude.json` 里有这个键、`osm-buildings.geojson` 里有对应轮廓 |
| `floor` | 建议 | 楼层，纯数字或 `"B1"`；拿不准就留空 |
| `name_*` | 可选 | 教室名（如「大講義室」），无名教室留空 |
| `aliases` | 建议 | 别名 / 学生俗称 / 课表变体写法，全部进搜索索引 |
| `seats` | 可选 | 座席数，来源没写就不填 |
| `source` | ✅ | 该条事实的出处 URL |

`building` 怎么查：`annotations-claude.json` 的 key 就是 OSM way id，含 84 栋建筑的三语名，
按名字反查即可。常用速查：

- センター1〜6号館 = 165694547 / 165694554 / 329404792 / 900236665 / 165694577 / 222850629
- ウエスト1 / 2 / 4 / 5号館 = 10012235450 / 10019151271 / 10019151272 / 10012235222
- 西講義棟 = 167423392 · 総合学習プラザ = 10019151273
- East 1 / 2号館 = 770575334 / 770575335 · 大講義室Ⅰ / Ⅱ = 770575332 / 770575333
- 椎木講堂 = 617112195
