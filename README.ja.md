# H5-Kyudaiguide — 九州大学伊都キャンパス ガイド＆インタラクティブマップ

[English](README.md) · **日本語** · [简体中文](README.zh.md)

> 九州大学伊都キャンパスの、多言語・オフライン対応の**キャンパスガイド＋インタラクティブ地図**。
> 同時に、公式地図 PDF のあるどのキャンパスにも移植できるオープンな**パイプライン**でもあります。
> 留学生・新入生向け：教室・事務室・施設を探す、バスを調べる、徒歩ルートを引く、生活ガイドを読む——
> アプリ不要、オフラインでも動きます。

**オンライン**（GitHub Pages 有効化後）:
- 🗺️ 地図 — `https://hanbinglei.github.io/H5-Kyudaiguide/h5-mvp/app.html`
- 📖 ガイド — `https://hanbinglei.github.io/H5-Kyudaiguide/guide/`
- 📦 オフライン単一ファイル（ダブルクリックで起動、WeChat/LINE でそのまま共有可）—
  [`dist/kyudaimap-offline.html`](dist/kyudaimap-offline.html)（2.7 MB、ネットワークリクエストゼロ）

## 二つの顔

1. **完成品** —— 今すぐ使える九大伊都キャンパスの地図とガイド。
2. **方法論** —— 「公式地図 PDF ＋ オープンデータ」を「オフライン対応のインタラクティブ地図」に
   変える完全なパイプライン。データソースと基準点を差し替えれば、コードはほぼそのままで
   **あなたの学校の地図**が作れます（[他校への移植](#他校への移植) 参照）。

## 機能

### 📖 ガイド（`guide/`、静的 H5）

キャンパスガイドの読み取り専用 H5 版——コンテンツ 4 タブ＋公式サイトリンク、バックエンド・アカウント不要：

- **ガイド** —— 12 シーン別の生活ガイド（入国準備・在留手続・住まい・銀行・SIM・奨学金・
  アルバイト・医療・交通・生活のコツ・買い物・緊急連絡）、ローカルのコンテンツブロックから描画。
- **村暦** —— 学年暦＋祝日カレンダー（内閣府の国民の祝日＋九大学年暦）。
- **地図** —— 下記のインタラクティブ地図を埋め込み。
- **履歴** —— 閲覧履歴（localStorage）。
- **公式サイト** —— **12 学部＋21 大学院学府**の公式サイトへのワンタップリンク。
  キャンパスタグ付き、出典は九大公式の学部・大学院一覧。
- UI は 4 言語（中・日・英・韓）。

### 🗺️ 地図（`h5-mvp/`）

- **検索**（統一検索ボックス、曖昧フォールバックで空振りしない）
  - 建物 84 棟（公式番号＋三言語ラベル）· 教室 136 室（`2304` / `A-101` / `工学部第5講義室`）
  - **事務室 21 か所**（部署 → 建物 → 階 → 部屋番号、例「国際部 留学課 · センター4号館 4F 401」）
  - 学外の学部 11（伊都にないものはキャンパス名のみ表示、ナビはしない——無駄足を防ぐ）
  - 施設 233 点：食堂／売店／ATM／トイレ／**AED／駐車場／校門／出入口**
- **意図クエリ**：「食堂はどこ / 食堂在哪里 / where is toilet」と入力 → 距離順に一覧＋地図にピン
  （7 言語、アクセント無視の許容つき）
- **🚌 昭和バス**：3 路線の地図アニメーション（時刻表から車両位置を推定、お盆・日跨ぎ対応）＋
  バス停タップで当日の時刻表と次発カウントダウン
- **徒歩ナビ**：任意 2 点間の A* ルート（OSM 歩行ネットワーク 4,411 ノード、階段重み付け）、
  初回に「参考程度」の免責を表示
- **7 言語**：中・日・英・韓・ヒンディー・西・仏、即時切替、設定はローカル保存
- **位置情報**：📍 GPS 地点を自動でルート起点に（ブラウザ制限時は丁寧に案内）

## 移植可能な 3 つのコア技術

このプロジェクトの見どころは「この九大地図」ではなく、他でも使える次の 3 つのやり方です：

### ① 公式ベクター PDF → 緯度経度（局所ジオリファレンス）

公式キャンパスマップは PDF で、座標はイラスト座標であって地理座標ではないことが多い。
やり方：PDF から建物番号記号を抽出 → 「番号 ↔ 既知の緯度経度」の基準点群で
**MLS（移動最小二乗法）局所アフィン補間** → PDF 上の任意の点から緯度経度を得る。
残差は**中央値 2.8 m**（建物レベルで信頼可）。同じ方法で AED・駐車場・校門などの記号も抽出。
→ `tools/extract_markers.py` · `georef_assign.py` · `extract_facility_icons.py`

### ② 公開時刻表 → 構造化データ → 純フロントエンドのアニメーション

NaviTime 掲載の昭和バス公式時刻表から 3 路線 226 便を取得（Jina Reader でページ取得＋正規表現、
リンクの `day=` パラメータで平日／土／日祝を判別）、内閣府の祝日表と組み合わせ。
フロントエンドは**時刻表＋東京時間のみ**で車両位置を推定——リアルタイム通信ゼロ、オフラインでも動き、
**お盆臨時ダイヤ**と**日跨ぎ最終便**という 2 つの落とし穴も処理済み。
→ `tools/build_bus_schedule.py` · `build_bus_routes.py` · `build_jp_holidays.py`

### ③ オフライン単一ファイルビルド

Leaflet＋ベクター基図＋全データを 1 つの HTML にインライン化。`loadData()` はデュアルモード
（インライン優先、なければ fetch）。各置換にアサーションを付け、テンプレートが変わったら
静かに壊れたファイルを作らず明示的に失敗する。成果物は 2.7 MB、ダブルクリックで起動。
→ `tools/build_offline.py`

**一貫した原則**：データは「欠け」を「捏造」より優先。決定的に導出できるものだけ補完し
（教室の階は番号から推定）、信頼できる出典のないものは空欄のまま、座標は絶対に作らない
（農場・無名建物の AED 8 か所は未配置のまま、公式番号の欠番 17 個も推測しない）。

## データパイプライン（`tools/`、公式地図や OSM の更新後に再実行可能）

| スクリプト | 出力 | 説明 |
|-----------|------|------|
| `extract_markers.py` / `georef_assign.py` | markers / assignments.json | PDF 番号抽出＋MLS ジオリファレンス（①の基盤）|
| `rebuild_geojson.py` + `merge_relations.py` | osm-buildings.geojson | OSM 建物輪郭（**way + relation 両取得**、連結棟は relation）|
| `build_annotations.py` | annotations-claude.json | 三言語の建物ラベル＋POI |
| `build_classrooms.py` | classrooms.json | 教室ライブラリ（公式講義室ページ＋工学部/IMI の PDF）|
| `extract_facility_icons.py` + `merge_official_extras.py` | facilities.json | 施設点（ATM/売店/WC/AED/駐車場/校門；AED は建物名で重心にマッチ）|
| `build_offices.js` + `offices-src/*.draft.json` | offices.json | 事務室（草案 → 学府別名の折り畳み、`node` 単体で再実行可）|
| `build_bus_schedule.py` / `build_bus_routes.py` / `build_jp_holidays.py` | bus-*.json / jp-holidays.json | バス時刻表／経路／祝日（②）|
| `build_graph.py` | route-graph.json | OSM 歩行ネットワーク → A* グラフ |
| `build_categories.py` / `build_boundary.py` / `build_basemap.py` | （色分け／キャンパス境界／オフライン基図）| UI データ層 |
| `build_offline.py` | dist/kyudaimap-offline.html | オフライン単一ファイル（③）|

アノテーションツール：`h5-mvp/osm-clean.html`（建物をクリック → 三言語名を入力 → JSON 出力）。

## データの出典とライセンス

| データ | 出典 | ライセンス／備考 |
|--------|------|------|
| 建物輪郭／歩行網／施設 | OpenStreetMap | ODbL、「© OpenStreetMap contributors」の帰属表示が必要 |
| 建物番号／記号のジオリファレンス元 | 九大公式地図 PDF | 著作権は九州大学；ジオリファレンス参照のみに使用、原図は再配布せず |
| バス時刻表 | 昭和バス（NaviTime） | 事実情報；出典と取得日を明記；ダイヤ改正は公式サイトが正 |
| 国民の祝日 | 内閣府 CSV | 公開データ |
| 事務室情報 | 九大各公式サイトから人手で整理 | 各項目に source/confidence 付き（草案参照）|
| 学部・学府サイトリンク | 九大公式 学部・大学院一覧 | 2026-08-24 取得；各単位の公式サイトへのリンク |

> ⚠️ **公式 PDF／地図画像はこのリポジトリに含まれません**（著作権は九州大学、再配布せず）。
> パイプラインが使う `ITO_1_Eng.pdf`、`kyudai_map_Ito_E_2026.pdf` 等は九大公式サイトから入手し
> リポジトリルートに配置してください——下記「データソースの自己調達」参照。
> コードは MIT；データは各出典のライセンスに従います（OSM 派生部分は ODbL 拘束——
> [DATA-LICENSE.md](DATA-LICENSE.md) 参照）。

### データソースの自己調達

以下のファイルは著作権上リポジトリに同梱しません。九大公式サイトからダウンロードして
リポジトリルートに置けば（ファイル名は維持）パイプラインを再実行できます：

| ファイル | 用途 | 入手先 |
|---------|------|--------|
| `ITO_1_Eng.pdf` | 建物番号／記号のジオリファレンス元（①の核心）| 九大公式 伊都キャンパスマップ（英語版）|
| `kyudai_map_Ito_E_2026.pdf` | 交通・周辺図 | 同上 |
| `mech-lecture.pdf` / `west1-layout.pdf` など | 工学部の教室配置 | 各学部公式サイト |

> **オンライン版／オフライン単一ファイル**（`h5-mvp/app.html`、`dist/`）を使うだけなら
> これらの PDF は不要です——データは `h5-mvp/data/` に抽出済み。
> `tools/` の抽出・ジオリファレンススクリプトを再実行する時だけ必要です。

## 他校への移植

1. `ITO_1_Eng.pdf` をあなたの学校の公式地図 PDF に差し替え、`markers`＋`assignments` の基準点を再構築（①）。
2. `rebuild_geojson.py` で自校キャンパスの bbox から OSM 建物を取得；`build_annotations` で名前を記録。
3. 教室／事務室／バスは `*.draft.json`＋各 `build_*` スクリプトでデータソースを埋める。
4. `build_offline.py` でオフライン単一ファイルを出力。
   —— フロントエンドの `app.html` はほぼ無改造；変えるのは `data/` と数個の基準点だけ。

## 限界（正直に）

- **時間とともに劣化します**：ダイヤ改正、建物の変化。データには `fetched` 日付が付き、
  スクリプトで再生成できます——定期的に再実行し、静的な真実として扱わないでください。
- バスは**往路のみ**（駅 → 九大）；復路は未対応（`build_bus_schedule.py` に `updown=1`）。
- 単一ファイル HTML は配布向きで、多人数での共同開発向きではありません。
  位置づけは「方法のサンプル＋fork 可能なテンプレート」に近いです。
