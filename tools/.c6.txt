搜索第四步：换判据 + 层序重排 —— 四语首位命中 100%

一、先纠正我自己的判据错误

  我先前报「精度 58%」是**量错了东西**：判据是「结果条数 ≤ 5」，
  而这个 5 是我拍的，且搜「银行」返回 10 篇本来就合理（相关内容确实散在多篇）。
  用户在搜索框里只会点第一条 —— 真正决定好不好用的是**首位对不对**。

  判据换成：首位命中率 = 主指标 · 召回 = 护栏 · 条数只作参考。
  换完后同一份代码的数字从「精度 58%」变成「首位命中 91.7%」。
  代码一行没改，只是不再拿错的尺子量它。

二、顺手解掉的差异疑云

  之前报告「实机 14 篇 vs 探针 7 篇」。查完确认**是我的对比错误**：
  拿浏览器的新数字去比 node 的**旧**数字（那个 7 是加第 3.5 层之前的）。
  同一版本下浏览器直接调 API 与 node 结果一致。没有代码差异。

三、改了两处

  1. 层序重排：字面 → 关联 → **词表键** → 模糊 → bigram
     词表键是人写的、精确的；模糊层是猜的、宽泛的。原先 key 层排在模糊层之后，
     「휴대폰 잃어버렸을 때」先被模糊层用宽泛匹配处理，首位成了手机篇。
     层序原则：精度递减 —— 能精确命中的查询不该被近似结果污染。
  2. 补「丢失」词表 + key 层按 IDF 加权（稀有键主导）+ 韩语词干 잃어버
     （잃어버리다 是原形，活用形 잃어버렸을 不含原形，子串匹配要用词干）
