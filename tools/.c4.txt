搜索第二步：医疗词表补全 + sub 层打分修正

用户指出「排序不是重点，是能不能搜到最相符的东西」—— 按这个方向做完剩余部分后：

上一轮我以为日文「風邪をひいたら」是**排序**问题（返回 10 篇、前三名全错），
还据此改了 sub 层的打分（关加成 + IDF 加权）。改完数字**一点没动** ——
说明判断错了。查下去真因是**词表**：

  医疗篇的日文正文写的是「体調不良と受診」，里面根本没有「風邪」。
  所以 sub 层只能拿「ひい」「いた」这类 bigram 碎片凑出 10 篇噪声，
  而正确的医疗篇压根不在结果里。
  这和英文的「查询说 sick、正文写 unwell」是同一个根因，不是两个问题。

修法：把读者说症状的词补进同义组（正文的「体調不良」也一并进组）：
  風邪 / かぜ / 体調不良 / 具合 / 症状 / 病気 / 医者 / 医生 / 大夫 / 診察
  sick / ill / unwell / symptom / doctor / feeling unwell
  아프다 / 아픈 / 아플 / 아픔 / 증상 / 의사（韩语的活用形也要，否则 아프다 匹配不到 아플）

同时保留 sub 层的打分修正 —— 它对「用碎片凑出的结果」是对的（bigram 命中标题
毫无意义，+30 的标题加成会压过词本身的证据）。只是它不是「風邪」那条的真因。

结果（24 条四语真实查询）：
  召回   22/24（91.7%）→ 23/24（95.8%）
  英文    4/5 → 5/5（sick 那条修好）
  旧基准 88.5% / 100% 完全不变（零回归）
